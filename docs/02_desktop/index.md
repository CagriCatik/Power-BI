# Power BI Desktop – Installation and Initial Setup

## Overview

**Power BI Desktop** is the primary authoring tool for creating Power BI reports and dashboards. It runs exclusively on **Windows** and provides all the capabilities to connect to data sources, transform data, and build interactive visualizations.

This chapter explains how to install Power BI Desktop, perform initial setup, and ensure key features are enabled for an optimal experience.

---

## Installation Requirements

* **Operating System:** Windows (Power BI Desktop is not natively available for macOS or Linux).
* **Internet Connection:** Required for downloading updates and connecting to online data sources.
* **Administrator Access:** May be needed to install the application on your computer.

---

## Installing Power BI Desktop

You can install Power BI Desktop in one of two ways:

### Option 1 – Microsoft Store (Recommended)

1. Open the **Microsoft Store** on your Windows device.
2. Search for **Power BI Desktop**.
3. Click **Install**.
4. Updates are handled automatically by the Store.

### Option 2 – Direct Download

1. Visit the official [Power BI Download Page](https://powerbi.microsoft.com/desktop/).
2. Download the latest **.msi installer**.
3. Run the installer and follow the setup wizard.
4. Check for updates regularly to keep your version current.

---

## Keeping Power BI Desktop Up to Date

Microsoft updates **Power BI Desktop monthly**, adding new features and improvements. To ensure you have the latest capabilities:

* If installed via the **Microsoft Store**, updates are automatic.
* If installed via direct download, manually check for updates on the [Power BI website](https://powerbi.microsoft.com/desktop/).

---

## Initial Setup

After installing Power BI Desktop:

1. **Launch the Application**
   Open Power BI Desktop from the Start menu or desktop shortcut.

2. **Sign In**

   * Use your organizational or Microsoft account for access to publishing and online features.

3. **Configure Options**

   * Go to **File > Options and Settings > Options**.
   * Adjust settings such as:

     * **Preview Features:** Enable experimental features like Visual Calculations or other tools as needed.
     * **Regional Settings:** Set default locale, date, and number formats.
     * **Global Settings:** Adjust data load, privacy levels, and performance options.

---

## Key Points to Check

* **Preview Features:** Some new tools (like Visual Calculations) may need to be manually enabled.
* **Updates:** Make sure you are on the latest version to access new monthly features.
* **Settings Backup:** Consider noting any changes you make to options in case you reinstall Power BI Desktop.

---

## Summary

Power BI Desktop is a **Windows-only** application that receives **monthly updates** from Microsoft. Installation can be done through the Microsoft Store (automatic updates) or direct download. After installation, configure key settings—especially **Preview Features**—to take advantage of the latest tools. Ensuring you stay updated guarantees access to new features and improvements for creating and managing Power BI reports efficiently.
