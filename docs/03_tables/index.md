## Why Start with Tables?

* **Data verification** — inspect raw values before building charts.
* **Aggregation clarity** — see sums, averages, and counts side-by-side.
* **Cross-filter testing** — confirm that clicking one visual filters another correctly.
* **Client-friendly output** — stakeholders often request exportable tabular data alongside dashboards.

> **Reference:** [Create and Format Table Visualizations in Power BI – Microsoft Learn](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-tables)

## Prerequisites

Before starting this section ensure you have:

1. Power BI Desktop installed and a `.pbix` file open (or a blank file with data loaded).
2. At least one table loaded in the model with text and numeric columns.
3. Basic familiarity with the Report View canvas and the Fields pane.

---

## What You Will Learn

By the end of this section you will be able to:

* Add a table visual to the report canvas and populate it with fields.
* Format column headers, cell backgrounds, fonts, and borders.
* Apply **conditional formatting** using background color scales, data bars, and icons.
* Use **cross-filtering** to make tables interact with other visuals.
* Change the **aggregation method** of numeric columns (Sum, Average, Count, Min, Max, etc.).
* Complete hands-on activities that reinforce each concept.
