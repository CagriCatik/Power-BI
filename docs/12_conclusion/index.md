## The Power BI Development Loop

The skills in this course form a repeatable workflow:

1. **Connect** — bring data in via Power Query from files, databases, or cloud services.
2. **Transform** — clean, reshape, and type the data in the Query Editor.
3. **Model** — define relationships, calculated columns, a Date table, and measures.
4. **Visualize** — build report pages with well-chosen visuals, filters, and interactivity.
5. **Publish** — push to the Power BI Service, organize in workspaces, and distribute via apps.
6. **Refresh** — schedule or trigger dataset refresh so reports stay current.
7. **Iterate** — use usage metrics and stakeholder feedback to improve reports.

## What to Learn Next

Power BI is a continuously evolving platform. After completing this course, the natural next steps are:

### Advanced DAX

* Iterator functions: SUMX, AVERAGEX, MAXX, RANKX
* Context transition and the EARLIER function
* Virtual relationships with TREATAS
* Row-Level Security (RLS) with USERPRINCIPALNAME()

### Advanced Power Query

* Custom M functions for reusable transformations
* Parameterized queries for dynamic data sources
* Handling API pagination and incremental load
* Query folding — understanding when transformations push to the source

### Data Modeling

* Composite models (DirectQuery + Import)
* Aggregation tables for large datasets
* Microsoft Fabric and Direct Lake mode

### Power BI Administration

* Tenant settings and governance
* Workspace lineage and impact analysis
* Capacity management (Premium / Fabric)
* Deployment pipelines (Dev → Test → Prod)
