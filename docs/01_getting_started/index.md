# Introduction to Power BI

## Purpose and Scope

This course serves as a structured, comprehensive introduction to Microsoft Power BI, covering both **Power BI Desktop** and the **Power BI Service**. It is designed for business analysts, data professionals, and technical users aiming to develop skills in interactive reporting, data modeling, and dashboard publishing using Microsoft’s self-service BI platform.

You will learn to transform raw datasets into dynamic, shareable insights using Power BI’s end-to-end capabilities—ranging from data transformation and modeling, to advanced visualization and report deployment.

---

## Tutorials Components

The tutorial is divided into several sequential modules that provide both theoretical understanding and practical, hands-on skills across the Power BI stack:

### Overview of Power BI Ecosystem

* **Power BI Desktop**: A Windows application for data import, modeling, and report design
* **Power BI Service**: A cloud-based platform for report sharing, collaboration, and governance
* Overview includes:

  * Interface orientation
  * Key functional differences
  * Integration between Desktop and Service

### Core Visualizations and Formatting

You will work with various data visual elements to create rich, interactive reports:

| Visualization Type    | Features Covered                                      |
| --------------------- | ----------------------------------------------------- |
| **Tables**            | Data listings, conditional formatting                 |
| **Matrix**            | Hierarchical row/column structure with measures       |
| **Cards**             | Single-value KPIs, formatting for performance metrics |
| **Column/Bar Charts** | Comparative graphical representation                  |
| **Line Charts**       | Trend analysis and time series visualizations         |

Formatting techniques include:

* Data label configuration
* Title, border, and background styling
* Color encoding for business context

### Filters and Interactivity

Power BI supports multiple methods of filtering and interactivity:

* **Report-level filters**
* **Page-level filters**
* **Visual-level filters**
* **Slicers**:

  * Dynamic user filters via dropdowns, sliders, or checkboxes
* **Cross-filtering**:

  * Clickable visuals that impact other visual components

You will learn to build **fully interactive reports** that dynamically respond to user actions.

### Publishing and Enhancing Reports in the Service

After report development, we transition to Power BI Service:

* **Publishing Reports** from Desktop
* **Creating Dashboards** by pinning visuals
* **Q&A Feature**:

  * Natural language querying of datasets
* **App Workspaces**:

  * Organize and collaborate on BI content
  * Define access roles (Admin, Member, Viewer)
* **Publishing Apps**:

  * Packaged reports and dashboards for end-users

### Data Modeling Fundamentals

A critical part of Power BI development lies in **semantic modeling**. You will:

* Create **Calculated Columns**:

  * Row-context based computations stored in the table
* Create **Measures**:

  * Aggregation logic applied at runtime to visualizations
* Define **Relationships** between tables
* Understand cardinality and filter propagation
* Implement **Data Normalization Best Practices**

### External Integration

You will also explore how Power BI integrates with other productivity tools:

* **Excel**:

  * Export to Excel
  * Analyze in Excel with OLAP connections
* **PowerPoint**:

  * Export report visuals to slides
  * Maintain interactivity via Power BI add-ins

### Power Query Editor

The course introduces **Power Query**, also known as the **Query Editor**, for data preparation:

* Data extraction (from files, databases, web, etc.)
* Data transformation:

  * Column splitting, pivot/unpivot, change types
* Data cleaning:

  * Remove duplicates, handle nulls
* Merge and append queries
* Applied Steps and M Code fundamentals

## Prerequisites and Environment Setup

* No programming knowledge required
* Windows 10+ required for Power BI Desktop
* Microsoft account (work email) required for Power BI Service
* Stable internet connection recommended

---

## Tutorial Philosophy

The course emphasizes a **layered approach to learning**:

1. **Understand the tools** (Power BI Desktop + Service)
2. **Learn to visualize**
3. **Learn to interact**
4. **Learn to model**
5. **Learn to share**
