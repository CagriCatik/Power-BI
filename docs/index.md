# Power BI Course

Learn Microsoft Power BI from first steps to advanced reporting, DAX (Data Analysis Expressions), and publishing. This site hosts the complete course material, organized to take you from installation to interactive, production-ready reports.

---

## Overview

This course covers:

* Installation and setup of Power BI Desktop and Service
* Data loading, shaping, and modeling with relationships and DAX
* Core visuals, filters, slicers, and visual calculations
* Interactive dashboards, publishing, and app workspaces
* Integrations with Excel and PowerPoint
* Hands-on activities with provided datasets and solutions

---

## Course Structure

### 1. Getting Started with Power BI

Set up your environment and learn the basics.

* Introduction to Power BI and course objectives
* Download the training data files
* Sign up for the Power BI Service
* Load data into the Power BI Service
* Practical activity: initial setup

### 2. Power BI Desktop Overview

Understand the desktop interface and configuration.

* Options and settings
* Interface layout and main panes

### 3. Working with Tables

Create, format, and analyze data with tables.

* Table creation and formatting
* Cross-filtering and aggregation
* Practical activities and solutions

### 4. Visualizations -- Matrix and Cards

Build summary views for KPIs and dimensional analysis.

* Matrix visuals and configuration
* Card visuals for single-value metrics
* Practical exercises and solutions

### 5. Dates and Visual Calculations

Work effectively with dates and built-in visual calculations.

* Date management and formatting
* Visual-level calculations and use cases
* Practical setup and scenarios

### 6. Filters and Slicers

Control scope and interactivity for analysis.

* Text, numeric, and date slicers
* Visual-, page-, and report-level filters
* Practical activities with solutions

### 7. Graph Visualizations

Create charts for comparison, composition, and trends.

* Clustered, stacked, and 100 percent charts
* Options, trend analysis, and forecasting
* Reference lines and additional chart types
* Practical challenges and solutions

### 8. Interactive Dashboards and Reports

Design, publish, and share interactive experiences.

* Building interactive dashboards and reports
* Publishing to the Power BI Service
* Pinning visuals to dashboards
* Mobile reports, Q&A visuals, app workspaces, and themes
* Using custom visuals

### 9. Data Modeling -- Columns and Measures

Model data with DAX for robust analytics.

* Calculated columns and measures
* Date functions and master date tables
* The CALCULATE function and DAX query view
* Hands-on activities with solutions

### 10. Relationships and Data Transformation

Connect and shape data for reliable models.

* Creating and managing relationships
* Relationship calculations
* Query Editor for data transformation
* Summary tables

### 11. Integration with Other Tools

Extend analysis and presentation.

* Power BI with Excel
* Power BI with PowerPoint
